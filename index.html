🎯 애플리케이션의 목적 (Application Purpose)

DD LifeLog(디디 라이프로그)는 사용자가 여러 언어로 개인 일기와 라이프로그를 작성하고 체계적으로 관리할 수 있도록 돕는 서비스입니다. Google Gemini AI 모델을 연동하여 작성된 일기의 의미 파악 및 동의어 연관 검색을 제공하고, 일상 기록을 안전하게 저장하는 것을 목적으로 합니다.

🔐 Google OAuth (Google 계정 로그인) 활용 목적

  • 안전한 사용자 인증: Google Sign-In을 통해 별도의 비밀번호 저장 없이 간편하고 안전하게 로그인합니다.
  • 개인 데이터 보안 동기화: 사용자의 일기 데이터를 Firebase Cloud 데이터베이스와 연동하여 여러 기기에서 안전하게 백업 및 동기화합니다.

🛡️ 개인정보 및 데이터 보호 약속

DD LifeLog는 로그인 인증에 필요한 최소한의 계정 정보(이메일, 기본 프로필)만을 참조하며, 사용자가 직접 작성한 일기 데이터는 철저히 암호화하여 보호됩니다. 어떠한 경우에도 외부 제3자에게 매매되거나 마케팅 목적으로 무단 활용되지 않습니다.
